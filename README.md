# Aayush Kumar Singh — Portfolio

A responsive, editorial-style portfolio built with Next.js 16 and React 19.

**Live site:** https://aayush-portfolio-swart.vercel.app/

## Run locally
```bash
npm install
npm run dev
```

## Highlights
- Responsive hero, selected work, experience, skillsets and contact
- Accessible light/dark switch with coordinated foreground/background tokens and saved preference
- Updated GitHub project links
- No new dependencies required

## Content
Project and experience content lives in `app/page.tsx`. Design tokens and layout styles are in `app/globals.css`.

The experience section is based on the supplied resume. Confirm all roles and metrics before public publication. To add a downloadable resume, place a reviewed PDF under `public/` and link it from the interface.
